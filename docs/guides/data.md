# Tables and information density

Use `Table` for markup and `DataTable` when sorting, filtering, pagination, or row actions are required. The Data section is the canonical full example.

- Keep headings and cells aligned to a stable column grid.
- Use semantic status badges instead of color alone.
- Put overflow actions in one centered button with an accessible label.
- Keep row action menus skeuomorphic in both themes and ensure hover icons remain readable.
- Make the table region horizontally scrollable on narrow screens instead of overflowing the page.
- Keep filtering controlled and debounce only when filtering a large dataset.
