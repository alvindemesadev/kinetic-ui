# Kinetic UI usage guides

Kinetic UI follows the shadcn-style source model: the component source stays in your project, and the Skeuomorphic tokens provide the visual contract. Start with the installation guide, then choose the pattern guide that matches the surface you are building.

## Guides

- [Installation and source ownership](./installation.md)
- [Theme tokens and customization](./themes.md)
- [Accessible forms and focus](./accessibility.md)
- [Overlays, drawers, and confirmations](./overlays.md)
- [Loading and async actions](./loading.md)
- [Tables and information density](./data.md)
- [Charts and deferred loading](./charts.md)
- [Migration from the template](./migration.md)

Every guide is intentionally short and points to the authoritative source files rather than duplicating component implementations.
